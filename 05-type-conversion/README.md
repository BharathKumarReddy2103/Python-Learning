# Type Conversion (Casting)

## Objective

Learn how to convert one data type into another.

## Concepts Covered

- int()
- float()
- str()
- Invalid type conversion

## Files

### 01-int.py

Converts user input into an integer.

### 02-addition.py

Performs arithmetic using converted integer values.

### 03-float.py

Converts user input into a float.

### 04-string.py

Converts an integer into a string.

### 05-invalid.py

Demonstrates an invalid conversion that raises a ValueError.

## Commands

```bash
python 01-int.py
```

```bash
python 02-addition.py
```

```bash
python 03-float.py
```

```bash
python 04-string.py
```

```bash
python 05-invalid.py
```

## Learning Outcome

- Understand why input() returns a string.
- Learn how to convert between data types.
- Understand common conversion errors.
