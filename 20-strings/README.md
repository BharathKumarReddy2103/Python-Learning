# Strings

## Objective

Learn the fundamentals of Python Strings, including indexing, slicing, iteration, membership testing, and string immutability. Strings are one of the most frequently used data types in Python and are essential for automation, backend development, API processing, and DevOps scripting.

---

## Why Strings Matter

Almost everything handled in DevOps and backend development is text.

Examples include:

- Linux command output
- Log files
- JSON payloads
- YAML configuration files
- AWS resource names
- Kubernetes pod names
- Docker image tags
- API requests and responses
- Environment variables

Understanding strings is the foundation for processing and transforming this data.

---

## Concepts Covered

- Creating strings
- Indexing
- Negative indexing
- Slicing
- String length
- Iteration
- Membership testing (`in`)
- String immutability
