# Loops

## Objective

Learn how to execute the same block of code multiple times using Python `for` and `while` loops.

Loops help automate repetitive tasks and are widely used in DevOps automation, backend development, cloud engineering, and scripting.

## Concepts Covered

- `for` loop
- `while` loop
- `range()` function
- Iteration
- Loop counters
- `break` statement
- Repetitive task automation

## Files

### 01-for-loop.py
Prints numbers using a basic `for` loop.

### 02-range.py
Demonstrates the `range()` function.

### 03-even-numbers.py
Prints even numbers using `range(start, stop, step)`.

### 04-table.py
Prints the multiplication table of a user-provided number.

### 05-while-loop.py
Demonstrates a basic `while` loop.

### 06-password-attempt.py
Allows up to three login attempts using a `while` loop and `break`.

### 07-devops-server-check.py
Simulates checking multiple servers.

### 08-kubernetes-pods.py
Simulates checking Kubernetes pod health.

### 09-cloud-monitor.py
Simulates monitoring multiple EC2 instances.

### 10-deployment-progress.py
Simulates deployment progress through multiple steps.

## Learning Outcome

After completing this lesson, you will be able to:

- Use `for` loops for fixed iterations.
- Use `while` loops for condition-based repetition.
- Work with the `range()` function.
- Automate repetitive tasks.
- Build scripts that process multiple items.
- Apply loops to DevOps, cloud, and backend scenarios.
