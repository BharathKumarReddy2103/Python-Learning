# If...Else Statement

## Objective

Learn how Python makes decisions using the `if...else` statement.

## Concepts Covered

- if
- else
- Comparison operators
- Decision making
- Indentation

## Files

### 01-if-else.py

Basic example of an if...else statement.

### 02-voting.py

Checks voting eligibility.

### 03-login.py

Validates a user password.

### 04-even-odd.py

Determines whether a number is even or odd.

### 05-salary.py

Checks whether a salary meets a threshold.

### 06-kubernetes-health.py

Checks Kubernetes pod health.

### 07-disk-monitor.py

Monitors disk usage and prints status.

### 08-devops-server-check.py

Checks server health status.

## Commands

```bash
python 01-if-else.py
python 02-voting.py
python 03-login.py
python 04-even-odd.py
python 05-salary.py
python 06-kubernetes-health.py
python 07-disk-monitor.py
python 08-devops-server-check.py
```

## Learning Outcome

After completing this lesson, you will be able to:

- Write if...else statements.
- Handle both True and False conditions.
- Build simple decision-making programs.
- Understand how backend APIs and monitoring systems make decisions.
