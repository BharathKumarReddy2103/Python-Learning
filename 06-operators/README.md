# Operators

## Objective

Learn how Python operators work to perform mathematical calculations and build application logic.

Operators are one of the most important concepts in programming because they are used in almost every application, from simple calculations to complex business logic in backend APIs.

## Concepts Covered

- Arithmetic Operators
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
  - Floor Division (//)
  - Modulus (%)
  - Power (**)

## Files

### 01-addition.py

Performs addition of two numbers.

### 02-subtraction.py

Performs subtraction of two numbers.

### 03-multiplication.py

Performs multiplication of two numbers.

### 04-division.py

Performs normal division using `/`.

### 05-floor-division.py

Performs floor division using `//`.

### 06-modulus.py

Finds the remainder after division using `%`.

### 07-power.py

Calculates the power of a number using `**`.

### 08-devops-calculator.py

A real-world example that calculates bonus amount and total salary using arithmetic operators.

### 09-cloud-cost-calculator.py

A practical example that calculates the total monthly AWS cloud cost by adding infrastructure and AWS support costs.

After completing this lesson, you will be able to:
