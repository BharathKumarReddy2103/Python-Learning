# Logical Operators

## Objective

Learn how to combine multiple conditions using Python logical operators (`and`, `or`, and `not`).

## Concepts Covered

- and
- or
- not
- Combining multiple conditions
- Authentication logic
- Backend validation
- DevOps monitoring

## Files

### 01-and.py
Demonstrates the `and` operator.

### 02-or.py
Demonstrates the `or` operator.

### 03-not.py
Demonstrates the `not` operator.

### 04-login.py
Validates username and password.

### 05-admin-access.py
Checks user role and department.

### 06-kubernetes-health.py
Checks Kubernetes pod and node status.

### 07-cloud-health.py
Checks CPU and memory utilization.

### 08-devops-deployment.py
Checks build and test status before deployment.

### 09-api-validation.py
Validates API token and user existence.

### 10-production-monitor.py
Checks production system health.

## Commands

```bash
python 01-and.py
python 02-or.py
python 03-not.py
python 04-login.py
python 05-admin-access.py
python 06-kubernetes-health.py
python 07-cloud-health.py
python 08-devops-deployment.py
python 09-api-validation.py
python 10-production-monitor.py
```

## Learning Outcome

After completing this lesson, you will be able to:

- Use `and`, `or`, and `not` operators.
- Combine multiple conditions effectively.
- Build authentication and authorization logic.
- Implement health checks for DevOps and cloud systems.
- Write cleaner conditional statements for backend applications.
