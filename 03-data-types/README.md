# Data Types

## Objective

Learn Python's basic built-in data types.

## Concepts Covered

- String
- Integer
- Float
- Boolean
- type() function

## Files

### 01-basic-data-types.py

Demonstrates different data types and checks their types using type().

## Commands

```bash
python 01-basic-data-types.py
```

## Learning Outcome

- Understand Python data types.
- Learn how to inspect the type of a variable.
