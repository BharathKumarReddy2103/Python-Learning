# File Handling

## Objective

Learn how to use Python File Handling to create, read, write, append, and process files. File handling is an essential Python skill for DevOps automation, log processing, configuration management, report generation, and system administration.

---

## Why File Handling Matters

DevOps automation frequently works with information stored in files.

Examples include:

- Application logs
- Kubernetes logs
- Deployment logs
- Configuration files
- Server inventories
- Environment files
- AWS configuration files
- CI/CD reports
- Backup files
- Automation output

Python File Handling allows scripts to read, modify, analyze, and generate this information automatically.

- Creating files

- Reading files
- Writing files
- Appending data
- Reading a single line
- Reading multiple lines
- `read()`
- `readline()`
- `readlines()`
- `write()`

- File modes
- `with open()`
- File objects
- Processing log files
- Processing configuration files
- File-based DevOps automation

## File Modes

- `r` - Read
- `w` - Write
- `a` - Append
- `x` - Create a new file
