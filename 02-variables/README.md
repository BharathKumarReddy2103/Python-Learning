# Variables

## Objective

Learn how to store data in variables.

## Concepts Covered

- Variable declaration
- Variable assignment
- Updating variables

## Files

### 01-basic-variables.py

Stores employee information in variables and prints them.

### 02-update-variable.py

Demonstrates updating variable values.

## Commands

```bash
python 01-basic-variables.py
```

```bash
python 02-update-variable.py
```

## Learning Outcome

- Understand what variables are.
- Learn how Python stores values.
- Learn that variables can be updated.
