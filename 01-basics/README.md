# Python Basics

## Objective

Learn how to write and execute your first Python programs.

## Concepts Covered

- Writing the first Python program
- print() function
- Running Python scripts
- Understanding Python execution

## Files

### 01-hello.py

Prints "Hello, Bharath!"

### 02-intro.py

Prints a short introduction using multiple print() statements.

### 03-company.py

Prints employee information such as:

- Company
- Employee Name
- Role
- Experience
- Learning Goal

## Commands

Run any program:

```bash
python 01-hello.py
```

```bash
python 02-intro.py
```

```bash
python 03-company.py
```

## Learning Outcome

- Understand how Python programs execute.
- Learn to use the print() function.
- Become familiar with running Python programs from the terminal.
