# Input and Output

## Objective

Learn how to accept user input and display output.

## Concepts Covered

- input()
- print()
- Interactive programs

## Files

### 01-input.py

Reads input from the user.

### 02-name.py

Reads the user's name and displays a welcome message.

### 03-profile.py

Accepts multiple user inputs and prints a formatted profile.

## Commands

```bash
python 01-input.py
```

```bash
python 02-name.py
```

```bash
python 03-profile.py
```

## Learning Outcome

- Learn how to receive input from users.
- Understand interactive Python programs.
