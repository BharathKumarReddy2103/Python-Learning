# Conditional Statements

## Objective

Learn how Python makes decisions using conditional statements.

## Concepts Covered

- if statement
- Comparison operators
- Decision making
- Indentation

## Files

### 01-if.py

Simple if statement.

### 02-age-check.py

Checks voting eligibility.

### 03-salary-check.py

Checks salary threshold.

### 04-password-check.py

Simple password validation.

### 05-even-odd.py

Checks whether a number is even.

### 06-disk-space-check.py

Simulates a DevOps disk usage alert.

## Learning Outcome

After completing this lesson, you will be able to:

- Write if statements.
- Compare values.
- Build simple decision-making programs.
- Understand how backend APIs validate requests.
