# Nested if Statement

## Objective

Learn how to use nested `if` statements to perform multiple dependent checks.

## Concepts Covered

- Nested if
- Multiple levels of decision making
- Parent-child conditions
- Backend authentication logic
- DevOps health checks

## Files

### 01-basic.py
Basic nested if example.

### 02-login.py
Checks username and password.

### 03-bank-account.py
Validates PIN and account balance.

### 04-user-access.py
Checks role and department.

### 05-kubernetes-health.py
Checks cluster and pod health.

### 06-server-health.py
Checks server status and disk usage.

### 07-api-authentication.py
Validates API token and user.

### 08-cloud-resource.py
Checks EC2 instance and CPU usage.

### 09-database-check.py
Checks database connection and table existence.

### 10-production-health.py
Checks load balancer and application health.

## Commands

```bash
python 01-basic.py
python 02-login.py
python 03-bank-account.py
python 04-user-access.py
python 05-kubernetes-health.py
python 06-server-health.py
python 07-api-authentication.py
python 08-cloud-resource.py
python 09-database-check.py
python 10-production-health.py
```

## Learning Outcome

After completing this lesson, you will be able to:

- Write nested `if` statements.
- Understand dependent conditions.
- Build multi-step validation logic.
- Implement backend authentication flows.
- Build DevOps health check programs.
