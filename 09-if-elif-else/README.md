# If...Elif...Else Statement

## Objective

Learn how to make decisions with multiple conditions using the `if...elif...else` statement.

## Concepts Covered

- if
- elif
- else
- Multiple conditions
- Decision making

## Files

### 01-grade.py
Assigns grades based on marks.

### 02-salary.py
Categorizes salary into different ranges.

### 03-cpu-monitor.py
Monitors CPU usage levels.

### 04-http-status.py
Interprets HTTP status codes.

### 05-user-role.py
Displays messages based on user roles.

### 06-weather.py
Categorizes weather using temperature.

### 07-cloud-cost.py
Categorizes monthly cloud spending.

### 08-kubernetes-pod-status.py
Checks Kubernetes pod status.

### 09-devops-alert.py
Generates alerts based on memory usage.

## Commands

```bash
python 01-grade.py
python 02-salary.py
python 03-cpu-monitor.py
python 04-http-status.py
python 05-user-role.py
python 06-weather.py
python 07-cloud-cost.py
python 08-kubernetes-pod-status.py
python 09-devops-alert.py
```

## Learning Outcome

After completing this lesson, you will be able to:

- Use `if`, `elif`, and `else` together.
- Handle multiple decision paths.
- Write programs with multiple outcomes.
- Build backend logic similar to FastAPI APIs.
- Understand monitoring thresholds used in DevOps tools.
